# Fault matrix

> Status: **reference** (reviewed 5 Oct 2026). SIL = software-in-the-loop (host, deterministic, runs in CI). HIL = on the hardware rig. "Test ID" names an existing automated test where one exists. Detection times are in 10 ms frames.
> **Status is honest:** *Passing (SIL / host / live)* means an automated test has run and passed; *Rig pending* means the software side passes and the row is verified on the rig (nothing has run on a board); *Out of v1 scope* is a stretch goal.
